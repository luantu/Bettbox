# 雅迪快捷方式重复打开修复计划

> For agentic workers: use superpowers:executing-plans，主 Agent 实现与真机验证，独立只读复核会话边界。

**Goal:** 原桌面雅迪快捷方式可以连续打开，旧恢复任务不打断新请求。

**Architecture:** `CompatibilityLaunchSession` 管理代次、请求版本和在途启动；`CompatibilityAppManager` 复用暂停会话，在提交拉起／恢复／清理时核对同一状态。仅首次请求启动监控。

**Tech Stack:** Java、Kotlin、Android、GitHub Actions。

**Spec:** `docs/superpowers/specs/2026-10-26-雅迪快捷方式重复打开设计.md`。

## Global Constraints

不增加开关，不改 token、图标、桌面 ID、账号、订阅、脚本及地点配置；保留原提交历史。手机原 Wi-Fi 开、蜂窝关、常亮值 7、熄屏 60000 毫秒，定位时只临时延长熄屏并在结束恢复。
