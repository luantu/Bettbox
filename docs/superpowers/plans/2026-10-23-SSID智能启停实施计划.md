# SSID 智能启停实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 保留旧配置，增加 SSID 地点规则，统一前后台判定并交付验证过的 APK。

**Architecture:** 原生提供同一底层连接的网络快照；纯 Dart 规则及三态匹配器供两个执行入口共用。独立配置字段与编辑器不触碰授权和内核。

**Tech Stack:** Flutter/Dart、Android Kotlin、GitHub Actions。

**Spec:** docs/superpowers/specs/2026-10-23-SSID智能启停设计.md

## Global Constraints

保留 smartAutoStopNetworks 原值和全部其他配置。精确匹配 SSID，不读写凭据。手动停止及兼容暂停优先。不能用 IP 兜底一个不可读 SSID。构建延用现有签名和应用 ID。

## Review Focus

- 系统返回未知 SSID 时，不误停或误恢复。
- 多网络并存时不拼接不同接口条件。
- 删除最后规则及总开关关闭时释放智能暂停但不抹去用户停止意图。
- 锁屏、权限变化、切网与配置同步期间前后台结果一致。
- 老配置导入、无规则、损坏 JSON 不改变其他字段。
