# SSID 智能启停设计

在现有智能启停中增加地点规则，避免不同 Wi-Fi 使用相同私网地址时误停 VPN。用户已确认实施、保留配置、提交并触发构建，通过后在接入的手机上保留数据安装验证。

## 规则与状态

- 每条地点规则包含名称、启用开关、精确 SSID（区分大小写）、可选 IP/CIDR/网关。SSID 与地址条件同时满足；地址条件内部沿用任一地址或网关命中。不同地点规则任一命中即暂停。
- 可以仅 SSID 或仅地址，但不能保存空条件。新规则只匹配实际选中的物理底层网络；SSID 与地址必须来自同一个网络，不匹配 TUN 地址。
- 原 smartAutoStopNetworks 原值不改写，作为显式标注的“旧版 IP 规则”继续执行。添加地点规则不自动删除旧规则；提示旧规则仍可能在其他地点误命中，并提供编辑入口。
- SSID 不可读不是“不匹配”：短暂失败重试，持续不可读时保持实际启停状态并提示，不降低为仅地址匹配。明确离开 Wi-Fi 或读到其他 SSID 才解除该规则暂停。无网络时保持状态。
- 配置删除、停用或总开关关闭后，解除本功能拥有的暂停，但不能越过手动停止或雅迪兼容暂停。前台与后台共用纯 Dart 判定器；事件防抖、周期补偿、回前台重查覆盖锁屏与权限改变。
- 只申请读取已连接 Wi-Fi 所需权限，不扫描周边。权限按钮由用户主动点击；后台读取受系统权限限制时明确提示，不伪装为可用。SSID 本地存储，不向公共日志输出原始 SSID。

## 实现与验收

配置增加独立 JSON 字段保存地点规则，不改变旧字段和其他配置；无法解析的规则不得触发暂停。原生返回按网络关联的 SSID/IP/网关快照，前台与服务通道一致。页面沿用应用主题，提供规则编辑、当前连接状态、使用当前 Wi-Fi、权限引导和明确保存按钮。

验收包含：相同网段不同 SSID、相同 SSID 地址不符、跨接口误拼、SSID 未知、无网络、中文/带空格 SSID、空条件、旧配置往返、删除最后规则后的恢复、手动停止和兼容暂停优先、后台防抖与规则变动。先运行自动测试与完整 Actions；再模拟器；最后真机保留数据安装并验证当前网络规则、后台恢复和手动停止。SSID/网段不能作为网络安全认证。

## 方案取舍

不采用 SSID 列表与旧 IP 列表简单取或：仍有同网段误判。不采用全局强制“SSID 且所有 IP”：无法分别描述多个地点。采用独立地点规则，并保留旧规则显式兼容。
