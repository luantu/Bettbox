# 雅迪快捷方式重复打开设计

现有桌面快捷方式在第一次打开后、离开十秒的兼容会话结束前，会被 `active` 门控拒绝二次打开。手机已复现首次进入雅迪、Home 后快速重点击仍停桌面。修复目标是让同一个图标连续可用，同时保持雅迪前台时 VPN 暂停、离开后按原规则恢复。

## 实现选择

本次选择复用当前兼容会话重新拉起雅迪；尚在启动中的点击合并为同一任务。没有删除整个门控，也没有先恢复 VPN 再创建新会话，以免出现多个暂停拥有者、多个监控或引流短暂恢复。

Java 会话对象维护 `generation` 和请求 `revision`。首次请求负责暂停及唯一前台监控；之后的请求可以重新启动目标，不重复暂停。每次重开重置离开计时，保留本会话已经观察到雅迪前台的证据，避免短促打开被轮询漏采后无法结束会话。

自动恢复以及停止意图下的空闲清理，都必须核对当前代次、请求版本和无启动在途。实际拉起、显式恢复与保持停止在同一会话锁下提交；旧协程不能结束新会话。

## 约束与验收

不增加设置，不改快捷方式 token、雅迪图标或桌面 ID，不改授权、订阅、脚本、SSID 和网段。保留手动停止不自启及 SG 软暂停能力。

验收使用用户原有桌面图标，而非绕过 token 的直接 shell 启动：至少五轮打开→Home→十秒内再次打开均进入雅迪；持续前台不恢复 VPN，稳定离开后可恢复；恢复完成后还能再次打开。手动停止时仍能连续打开雅迪且 VPN 不自启。原生会话并发回归和完整 CI 通过后，用固定签名保留数据覆盖安装，记录最终 APK 的身份与实际结果。
